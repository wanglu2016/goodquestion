# GoodQuestion｜好问题

让自己的AI帮你找到值得继续的问题，也看见自己的提问还能怎样推进。

你想和AI探索一点有意思、有收益的东西，却不知道从哪里问起；或者已经问出了一句话，但觉得讨论还可以更有力。GoodQuestion提供一份可直接复制的指令，帮助你开始、展开和改进这样的对话。

## 立即使用

1. 打开 [goodquestion.md](goodquestion.md)，复制“复制区”中的全部文字。
2. 粘贴到自己的AI新对话里，发送。
3. AI会先给你三个思考起点。选择一个继续，或者直接提出自己的问题。

无需下载、安装、编程或申请API。下载文本只是方便保存；实际的生成和评价由你使用的AI完成，仍受该服务本身的使用限制。

## 两个功能

**开启探索和加强提问。** 没有明确问题时，AI提供能够进入的具体起点；已经提出问题时，AI保留你的意图，帮助找出更有力的切口。它可以利用已有背景帮助解释，但不应仅凭你的身份、历史兴趣或一次回答，限制后续探索。

**评价提问。** 评分默认关闭。开启后，AI按公开规则给实质问题提供参考分、简短理由和一个可选的推进方向。评价对象是当前问题的作用，不是提问者的能力。

## 自然地说就可以

| 你可以说 | AI会尝试做什么 |
| --- | --- |
| 开始／换一组 | 提供三个新的思考起点 |
| 继续第二个 | 展开所选问题 |
| 帮我把这个问题问得更有力 | 解释原问题的关键，并提供可选切口 |
| 开启评分／关闭评分 | 开关本次对话的提问评价 |
| 回顾这些问题 | 比较当前可见的问题，指出值得继续的地方 |

这些只是方便入口。你可以直接提问、质疑、要求解释，不需要记住命令。

## 怎样理解评分

满分10分：对当前目的的贡献0—4分，可推进程度0—3分，后续探索空间0—3分。详细规则在使用指令中。

分数是AI依照这套规则作出的参考判断，会受模型、上下文和对问题的理解影响。不要把它当作客观测量，也不必为了高分修改自己的好奇心。具体理由比相差一两分更值得看。

指令也不能保证消除记忆影响、每次产生好问题或一直被模型完整遵循。使用范围是采用指令的对话；它不会自动读取、评价你的全部历史聊天。
